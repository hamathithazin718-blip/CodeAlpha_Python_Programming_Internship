## 🚀 Projects Overview

### 1. Task 1: Hangman Game
* **Goal:** A text-based Hangman game where the player guesses a hidden word one letter at a time.
* **Features:**
  * Uses a predefined list of 5 words.
  * Limits incorrect guesses to a maximum of 6 attempts.
  * Clean console-based input and output feedback.
* **Key Concepts Used:** `random` module, `while` loops, `if-else` statements, strings, lists.
* **How to Run:**
  ```bash
  cd "Task 1"
  python <filename>.py
  ```

---

### 2. Task 2: Stock Portfolio Tracker
* **Goal:** A simple stock tracker that calculates total investment value based on manually defined stock prices.
* **Features:**
  * Accepts user input for stock ticker symbols and share quantities.
  * Uses a hardcoded dictionary of stock prices (e.g., `{"AAPL": 180, "TSLA": 250}`).
  * Calculates and displays the total investment value, with optional export to a `.txt` or `.csv` file.
* **Key Concepts Used:** Dictionaries, console input/output, basic arithmetic, file handling.
* **How to Run:**
  ```bash
  cd "Task 2"
  python <filename>.py
  ```

---

### 3. Task 3: Task Automation with Python Scripts
* **Goal:** Automate a small, repetitive real-life task using Python scripting.
* **Scope & Capabilities:** Automates tasks such as organizing `.jpg` files into a new directory, extracting email addresses from a `.txt` file using regex, or scraping and saving a webpage title.
* **Key Concepts Used:** `os`, `shutil`, `re` (regular expressions), `requests`, file handling.
* **How to Run:**
  ```bash
  cd "Task 3"
  python <filename>.py
  ```

---

### 4. Task 4: Basic Chatbot
* **Goal:** A simple rule-based conversational chatbot in the terminal.
* **Features:**
  * Recognizes common user inputs such as `"hello"`, `"how are you"`, and `"bye"`.
  * Responds with predefined replies like `"Hi!"`, `"I'm fine, thanks!"`, and `"Goodbye!"`.
* **Key Concepts Used:** Functions, `if-elif-else` conditional logic, loops, console input/output.
* **How to Run:**
  ```bash
  cd "Task 4"
  python <filename>.py
  ```

## 🛠️ Getting Started

### Prerequisites
* **Python 3.x** installed on your machine. Download it from [python.org](https://python.org).
* If your **Task 3** script uses web scraping, install the `requests` library:
  ```bash
  pip install requests
  ```

### Installation & Usage
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the repository folder:**
   ```bash
   cd CodeAlpha_Python_Programming_Internship
   ```
3. **Open any task folder and run its Python script.**
